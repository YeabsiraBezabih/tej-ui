Build reactive, zero-copy Rust UIs backed by Tej-DB.

tej-ui pairs 8-byte Copy topological signals, a flat Structure-of-Arrays (SoA) layout engine, instanced wgpu 24 rendering, and direct ACID commit hooks for tej-db.

src/main.rs 
use tej_ui::prelude::*;

fn counter_app() -> impl View {
    let count = Signal::new(0i32);
    let label = Memo::new(move || {
        format!("Count: {}", count.get())
    });

    VStack::new((
        Text::new("Hello from tej-ui"),
        Text::reactive(label.as_signal()),
        HStack::new((
            Button::new(Text::new("+1"))
                .on_click(move || count.update(|c| *c += 1)),
            Button::new(Text::new("-1"))
                .on_click(move || count.update(|c| *c -= 1)),
        )).spacing(8.0),
    ))
    .padding(24.0)
    .spacing(16.0)
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    App::new(counter_app())
        .window(WindowConfig {
            title: "Counter".into(),
            size: Size::new(480.0, 320.0),
            ..Default::default()
        })
        .run()?;
    Ok(())
}

Glitch-Free 8-Byte Signals

Generational Signal<T> handles are Copy even when T is not Clone, backed by topological BFS wave propagation, RAII panic guards, and explicit dispose().

Flat SoA Layout Engine

Structure-of-Arrays LayoutArena supports Flexbox alignment, margins, wrapping, and 2D CSS Grid row_span with cycle-safe tree ops and capacity-retaining reuse.

Direct Tej-DB Integration

Connects directly to tej-db 0.1.0 via DbSyncHook commit triggers, zero-copy DbRowLens slice views, and single-transaction snapshot-isolated secondary queries.

Instanced wgpu 24 + 128 Icons

Storage-buffer instanced quad, glyph, and Lyon vector pipelines with sRGB-to-linear decoding, HiDPI scaling, and a full SVG 1.1 arc/Bézier parser covering all 128 Lucide icons.

Hardened Security & A11y

Fail-closed SignatureVerifier OTA checks with SemVer downgrade protection, drop-zeroized SecureKeyStore, escaped ARIA attributes, and zero fabricated unsafe handles.

CLI & Headless TestHarness

Scaffold projects with tej-ui new my-app and run deterministic CI UI tests using TestHarness, MockClock, and SnapshotComparator.

Layered Zero-Circular-Dependency Architecture

Every subsystem compiles independently and composes cleanly through the tej-ui facade.
